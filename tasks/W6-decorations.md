# W6 Buffer decorations (stretch)

**Owns:** a `decorations` module in `crates/ui_ext_host/`, one hook in `crates/editor`.

**Deliverable:** a block decoration or inlay anchored to a CRDT anchor, fed by extension data.

**Starts after:** W3 has the panel container merged.

**Done when:** a demo extension adds a block under a line that survives edits above it.
