## 2. Статус на вкладці терміналу і панель Agent Sessions (5 хв)

Тут перевіряємо стан, який програма в терміналі повідомляє сама через OSC 7501 (так робить
Claude Code 2.1.295+). Щоб не чекати Claude, надсилаємо ті самі послідовності з PowerShell.

**2.1** Відкрийте термінал (**Ctrl+`**) і вставте:

```powershell
function osc($t){ $e=[char]27; [Console]::Write("$e]7501;$t$e\") }
osc 'state=working:app=claude-code:progress=40'
```

- Очікувано: на вкладці терміналу біля назви крутиться значок «працює». Якщо навести курсор:
  підказка `Claude Code: working`, нижче приблизно `40% · Claude Code via OSC 7501`.
- Якщо ні: нічого не з'явилося. Це може бути ConPTY (він інколи не пропускає невідомі OSC).
  Запишіть версію Windows і чи був хоч якийсь значок.

**2.2** Стан «чекає на вас» з текстом (заголовок передається в base64):

```powershell
$t=[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes('Run tests?'))
osc "state=blocked:kind=permission:app=claude-code:title=$t"
```

- Очікувано: значок попередження, біля нього крапка (потрібна ваша увага). Підказка
  `Claude Code: needs permission — Run tests?`.
- Якщо ні: скрін вкладки й підказки.

**2.3** Відкрийте панель **Agent Sessions**: кнопка із дзвіночком у правому доку (підказка
`Agent Sessions`; на ній число очікуваних) або палітра команд → `fyx terminal: toggle agent sessions`.
- Очікувано: у списку цей термінал: назва, рядок `Claude Code: needs permission — Run tests?`
  і рядок дрібніше з `via OSC 7501`. Термінали, що потребують вас, зверху. Клік по рядку переводить
  у цей термінал. Якщо жоден термінал не має статусу, панель каже `No terminal reports a status.`
- Якщо ні: скрін панелі.

**2.4** Сповіщення у фоні. Виконайте, і одразу перемкніться в інший застосунок (Alt+Tab), не закриваючи
Fyx:

```powershell

```

- Очікувано: у куті екрана на ~30 секунд з'являється невелике спливне вікно зі станом `done` і
  зеленою галочкою. Клік по ньому повертає у термінал.
- Якщо ні: чи було вікно взагалі; скільки чекали. (Вимкнути його можна налаштуванням
  `fyx.terminal.notifications`.)

**2.5** Верніться у Fyx і очистіть стан: `osc 'state=idle:app=claude-code'`.
- Очікувано: значок і крапка зникають; у панелі рядка немає.
- Якщо ні: що лишилося.

## 8. Shell integration: PowerShell і Git Bash (4 хв)

Fyx завантажує скрипт, що позначає підказки й команди (OSC 633) і підписує командний рядок
одноразовим ключем терміналу. Ваші власні файли запуску він не змінює. Налаштування
`fyx.terminal.shell_integration` (за замовчуванням `true`).

**8.1** Новий термінал **PowerShell** (як є). Виконайте:

```powershell
$Global:__FyxLoaded; "[$env:FYX_SHELL_NONCE]"; (Get-Command prompt).ScriptBlock.ToString() -match '633'
```

- Очікувано: перший рядок `True`; другий `[]` (ключ прибрано з оточення, програми його не
  бачать); третій `True` (підказка несе позначки OSC 633). Ваш профіль PowerShell і підказка працюють як раніше, `cd` змінює
  теку, команда з помилкою (`cmd /c exit 3`) не ламає наступну підказку.
- Якщо ні: що друкує перший рядок; чи є червоні помилки при старті.

**8.2** Git Bash. Додайте в `settings.json` (разом з наявним `terminal`, якщо він є):

```json
"terminal": { "shell": { "program": "C:\\Program Files\\Git\\bin\\bash.exe" } }
```

  Новий термінал, потім:

```bash
echo "loaded=$__fyx_loaded nonce=[$FYX_SHELL_NONCE]"
```

- Очікувано: `loaded=1 nonce=[]`; ваш `~/.bashrc` (aliases, підказка) працює.
- Якщо ні: що друкує; чи видно сире `]633;` у підказці (це збій розбору OSC).

**8.3** Поверніть PowerShell як оболонку (приберіть `shell` із `settings.json`). Змініть
`"shell_integration": false` у `fyx.terminal`, відкрийте **новий** термінал.
- Очікувано: у ньому `$Global:__FyxLoaded` порожнє. У вже відкритих терміналів нічого не
  змінилося. Верніть `true`.
- Якщо ні: що показує.
