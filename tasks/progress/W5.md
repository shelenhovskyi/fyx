  index under `.index`). The agent writes `secret://name` in a command or ACP env value; the window
  prompt asks per command; the command gets the shell's `FYX_SECRET_NAME` reference, the value is
  only in env. `Terminal::truncated_output` redacts the value and its base64/hex/URL forms. Uses are
  journaled without values in `data_dir/agent_review/secret_uses.jsonl`. Command palette:
  "agent review: manage secrets". Tests use a fake store and approver only. User doc:
  `docs/fyx/agent-review.md` "Secrets for agents".
