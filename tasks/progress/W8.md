Notes for the gatekeeper:
- Tests ran on Node 22.23 in a Linux container (the packages declare Node ≥ 24); not re-run on
  Windows. `npm run typecheck` is clean in both packages.
- The generated coverage report (21 Open VSX extensions) was not re-run: it needs the network
  fetch and the original Windows setup. Its per-extension numbers predate these fixes.
- New protocol: `push-update` now expects a JSON-RPC answer, plus `vscode/didChangeWatchedFiles`,
  `vscode/cancelProgress` (host → sidecar) and `vscode/setLanguageConfiguration` (sidecar → host).
  WIT `host.push-update` returns nothing, so the phase-3 Rust adapter must answer the request
  itself (an error when the tree rejects the update). A `result` return on `push-update` is a
  WIT change request for W0.
