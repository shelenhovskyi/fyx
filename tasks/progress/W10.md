## Gotchas

- **Line endings.** The checkout uses CRLF in the working copy (autocrlf), and git stores LF.
  - Write files with LF (Python `newline='\n'`).
  - Diff with `--strip-trailing-cr`.
  - `git apply` patches fail on the working copy. Copy the files over instead, or apply in a
    temporary LF tree.
- **Editing files.** Do larger edits with Python scripts in the scratchpad (exact
  `count == 1` asserts) instead of heredocs. Heredocs break on quotes, backslashes and `\0`.
- **Stash.** Never run a bare `git stash`: the stash is shared across worktrees. The
  fyx-extensions clone is a separate repository.
- **Pushing `main` of any repository** is the user's call. The coordinator relays a yes, and
  then it pushes itself.
- **Signed release fields.** `fyx_registry`'s Release is `deny_unknown_fields`. A new signed
  field needs the client to know it first.
- **The trusted review decision has no package.** Anything decided from package contents must
  also come from the source file list (`git ls-tree` at `source.commit`). Otherwise a PR can
  dodge it.
- **Run sheets.** Verify every UI string against the code on the refs in use, and pin the
  commits. Exe and material paths must be built from the same tree.
- **Wrap-up.** End every turn with a recap only: no questions, no buttons. Questions go to the
  coordinator.
