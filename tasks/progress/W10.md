## Gotchas

- **Line endings.** CRLF working copy (autocrlf), LF in git. Write files with LF (Python
  `newline='\n'`), diff with `--strip-trailing-cr`; `git apply` fails on the working copy.
- **Editing files.** Larger edits: Python scripts written with the Write tool into the scratchpad,
  with exact `count == 1` asserts. Not bash heredocs (quotes break them).
- **Backslash paths.** Never pass Windows paths through bash-quoted Python strings: `\f` becomes a
  formfeed and `\12` a newline (this broke fe4cdfa31b). Use raw strings in a Write-tool script and
  scan touched files for control characters before committing.
- **Stash.** Never a bare `git stash`: shared across worktrees.
- **Pushing `main` of any repository** is the user's call; the coordinator relays a yes and pushes.
- **Signed release fields.** `fyx_registry`'s Release is `deny_unknown_fields`: a new signed field
  needs the client first.
- **The trusted review decision has no package.** Anything decided from package contents must also
  come from git (`git ls-tree`, `extension.toml` at `source.commit`), or a PR can dodge it.
- **Run sheets.** Verify every UI string against the code on the refs in use and pin the commits.
  Exe and materials must come from the same tree.
